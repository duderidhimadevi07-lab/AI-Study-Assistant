# 🎓 AI Study Assistant

An AI-powered study assistant built with Python and Streamlit.

## Features

- 🤖 Ask AI
- 📝 Generate Notes
- ❓ Generate Quiz
- 📄 PDF Summarizer
- 📅 Study Planner
- 📊 Progress Tracker

## Technologies Used

- Python
- Streamlit
- SQLite
- PyPDF
- OpenAI API

## How to Run

1. Clone the repository
2. Create a virtual environment
3. Install dependencies
4. Run Streamlit
